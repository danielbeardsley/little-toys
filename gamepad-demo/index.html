Gamepad API Playground

A live look at what the browser's Gamepad API reports for every connected controller.

    🎮

    Connect a controller and press any button

    Browsers hide gamepads until you press a button on one (so pages can't fingerprint you). Plug in over USB or pair over Bluetooth, then press a button.

    Playground

    Every controller gets a blob. Left stick / D-pad moves · right stick looks around · A sparkles · B changes color · Y boings · right trigger grows · left trigger shrinks.

    Event log

    gamepadconnected / gamepaddisconnected are real browser events. The API has no button events, so presses and releases here come from comparing each frame's navigator.getGamepads() snapshot to the previous one.

      How it works

      window.addEventListener('gamepadconnected', (e) => {
  console.log('connected', e.gamepad.index, e.gamepad.id);
});

function frame() {
  for (const gp of navigator.getGamepads()) {
    if (!gp) continue;
    gp.buttons[0].pressed;   // boolean
    gp.buttons[7].value;     // 0..1 (analog trigger)
    gp.axes[0];              // -1..1 (left stick X)
  }
  requestAnimationFrame(frame);
}
requestAnimationFrame(frame);
